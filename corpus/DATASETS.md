## PRIMARY: Juliet C/C++ 1.3 (NIST SARD)

*   **URL**: `https://samate.nist.gov/SARD/downloads/test-suites/2017-10-01-juliet-test-suite-for-c-cplusplus-v1-3.zip`
*   **SHA-256**: `ada9d7e1c323d283446df3f55bdee0d00bda1fed786785fe98764d58688f38eb`
*   **Size**: 152,957,342 bytes
*   **License**: Public domain (US Government work — NIST SARD / NSA Center for Assured Software)
*   **Description**: 64,099 single-file C/C++ testcases across 119 CWE classes. Each testcase provides a flawed (`bad()`) and fixed (`good*()`) variant via `#ifndef OMITBAD` / `#ifndef OMITGOOD` preprocessor blocks.
*   **CWE coverage**: 119 classes (buffer overflow, integer overflow, format string, path traversal, command injection, use-after-free, double-free, memory leaks, etc.)
*   **Sampling for this corpus**: 40 CWE classes × 50 source files each (capped), yielding **3,054 samples** (1,527 vulnerable + 1,527 safe), balanced across CWEs.

## SECONDARY: Big-Vul (MSR 2020 C/C++ CVE Dataset) — *not fetched by default*

*   **URL**: `https://github.com/ZeoVan/MSR_20_Code_vulnerability_CSV_Dataset/raw/master/all_c_cpp_release2.0.csv`
*   **License**: MIT (original MSR dataset) — see upstream for terms.
*   **Description**: ~188k real C/C++ functions extracted from CVE commits, labeled with CWE and vulnerable/non-vulnerable flag. Useful for real-world recall signal.
*   **Status**: Disabled by default (`python corpus/fetch.py --datasets bigvul` to enable). Not included in this corpus because PRIMARY (Juliet) already satisfies acceptance criteria and provides synthetic but CWE-balanced ground truth. Big-Vul would add real-CVE recall at the cost of download time and less controlled CWE balance.

## Notes on SARD Python

NIST SARD does **not** publish a Python test suite. The SARD catalog lists C, C++, Java, C#, and PHP only. Therefore the "SARD Python" PRIMARY dataset mentioned in the task does not exist. The Python engine (`detect.py` + `taint_tracker.py` + `semantic_similarity.py`) is therefore unmeasured on public-domain labeled data — this is recorded as a coverage gap in `COVERAGE.md`.
