Capabilities

What it does

Offense

Kill Chain Synthesis

Chains individual findings into multi-step attack scenarios with MITRE ATT&CK mapping and severity escalation.

attestor killchain src/
Analysis

Inter-procedural Dataflow

Traces taint across function boundaries, through call graphs, with full evidence chains. The findings single-file scanners miss.

attestor interproc src/
Repair

AST-Aware Fix Engine

Plans and applies security fixes with reasoning chains, confidence scoring, and verification via re-scan. Not regex search-and-replace.

attestor plan-fix src/ --apply
Defense

IaC Security Scan

Dockerfiles, Kubernetes manifests, Terraform, Compose, GitHub Actions. Catches privileged containers, hardcoded secrets, host networking.

attestor iac infra/
Analysis

Symbolic Path Feasibility

Proves whether flagged paths are actually reachable. Prunes infeasible dead paths so you focus on what matters.

attestor sym-solve src/
Offense

Metasploit Bridge

Exports findings as a Metasploit resource script. Point, scan, exploit. Authorized pentesting only.

attestor msf . --rhosts target
